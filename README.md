# Sirius Desktop

Official desktop installers for [Sirius](https://sirius.kiranir.com), by Kiranir.

[Download the latest preview](https://github.com/Leonardocaff/sirius-desktop-releases/releases)
for Windows x64 or macOS (Apple Silicon and Intel). Use your existing Sirius
account. An internet connection is required.

## Preview status

The current preview has no verified publisher signature. Windows is unsigned.
macOS uses an ad-hoc signature, without Apple Developer ID or notarization.
Your operating system may prevent installation. Keep its security protections
enabled; [Sirius on the web](https://sirius.kiranir.com) remains available.

Each release includes versioned installers, release notes, `release.json` and
`SHA256SUMS.txt`. Checksums confirm file integrity, not publisher identity.
Published installers are immutable; fixes receive a new version.

Client updates are manual through Help → Downloads & updates. This repository
distributes binaries and release metadata only.

## Estado preliminar

Instaladores oficiales de Sirius para Windows y macOS. Usa tu cuenta habitual;
se requiere conexión a internet. La versión preliminar aún no tiene firma de
editor verificada ni notarización de Apple. El sistema puede impedir la
instalación. Mantén las protecciones del sistema activadas; puedes usar Sirius
en la web. Las actualizaciones del cliente se descargan manualmente.
